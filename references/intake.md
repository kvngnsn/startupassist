# Intake

Ask only what the requested documents need. Group questions, offer the market default in each question, and accept "use the default." Never invent a fact that goes into a signed document (names, share counts, prices, dates, addresses); if the user will not supply one, leave the `{{variable}}` in place and list it as an open item.

## 1. Always

1. What is the company's exact legal name (or proposed name), and has the Certificate of Incorporation been filed? If filed, on what date?
2. Where is the principal place of business, and in which states do employees or contractors work? (Drives employment law, foreign qualification, and state securities filings.)
3. Who are the directors and officers, and who signs for the company?
4. Is there a cap table? Ask for it, or for: authorized shares, par value, each holder's shares, outstanding options and the plan reserve, and every SAFE or note.
5. What has already been signed? Ask for the charter, bylaws, and consents before drafting anything that depends on them.

## 2. Formation

| Question | Default |
|---|---|
| Authorized Common Stock | 10,000,000 shares |
| Par value | $0.00001 |
| Blank-check Preferred at formation? | No |
| Incorporator | A founder (or counsel) |
| Registered agent | A commercial registered agent with a Delaware street address |
| Board size and members | All founders, or the CEO alone; odd number preferred |
| Officers | CEO, President, Secretary, CFO/Treasurer (one person may hold several offices) |
| Fiscal year | Calendar year |
| Company right of first refusal in bylaws | Yes, terminating at an IPO |
| Exculpation of officers (§102(b)(7)) | Yes |
| Exclusive forum (§115) | Delaware Court of Chancery; federal forum for Securities Act claims |

## 3. Founder stock

| Question | Default |
|---|---|
| Founders and their split | Must come from the user |
| Shares per founder | Total issued to founders is often 8,000,000–9,000,000 of 10,000,000 authorized |
| Price per share | Par value ($0.00001), paid in cash and/or by assignment of technology |
| Vesting | 4 years, 1-year cliff, monthly thereafter |
| Vesting commencement date | Date of issuance, or an earlier date crediting pre-formation work |
| Acceleration | Double-trigger, 100%, on an involuntary termination within 12 months after a change in control |
| Prior IP to assign | List the code, domains, designs, and other technology each founder created before formation |
| Founder residence, marital status, community-property state | Needed for the 83(b) mailing address and spousal consent |

## 4. Equity plan and grants

| Question | Default |
|---|---|
| Plan reserve | 10–15% of fully diluted capitalization at seed; size to the 12–24 month hiring plan |
| Award types | ISOs, NSOs, restricted stock, RSUs |
| Post-termination exercise period | 3 months (employees); longer periods convert ISOs to NSOs after 3 months |
| Early exercise | Allowed for founders/executives; optional for others |
| 409A valuation | Required before the first option grant; refresh every 12 months and after material events |
| Grant terms per person | Name, shares, ISO/NSO, vesting commencement date, schedule, acceleration, work state |

## 5. Hiring and service providers

| Question | Default |
|---|---|
| Employee or contractor | Apply the classification tests in references/employment-and-ip.md |
| Work state | Required; drives notices, non-solicit limits, pay transparency, arbitration |
| Exempt salary and title | From the user |
| Equity recommendation | Shares, not percentages; subject to board approval and the 409A price on the grant date |
| Non-compete | None (default); non-solicit only where enforceable |
| Arbitration | Optional; never for sexual harassment or assault claims at the employee's election |

## 6. SAFEs and convertible notes

| Question | Default |
|---|---|
| Instrument | YC post-money SAFE (valuation cap) |
| Valuation cap / discount | From the user; post-money cap stated as such |
| Round size and investors | From the user; confirm each investor is accredited |
| Side letters | Pro rata right only for designated major investors |
| Notes: interest, maturity, cap basis | 4–8% simple; 18–24 months; cap on a pre-money fully diluted basis |
| Exemption | Rule 506(b); no general solicitation |

## 7. Priced round

| Question | Default |
|---|---|
| Series, lead, round size, pre-money valuation | From the term sheet |
| Option pool after closing | Usually 10–15%, and say whether it is in the pre-money |
| Liquidation preference | 1x non-participating |
| Anti-dilution | Broad-based weighted average |
| Board composition | Seed: 2 Common, 1 Series; Series A: 2 Common, 2 Series, 1 Independent (or 2–1–0 / 2–2–1 variants) |
| Protective provisions | Requisite Preferred Holders (majority of Preferred, as a single class) |
| Major Investor threshold | A dollar amount set by the lead |
| Drag-along | Board + Requisite Preferred Holders (+ majority of Common held by Key Holders if negotiated) |
| Counsel fee cap for lead | From the term sheet |
| Converting SAFEs/notes | Every instrument, with cap, discount, amount, and date |

## 8. Governance and compliance

Ask what event is being approved, who must approve it (board, stockholders, a class), whether everyone will sign a written consent, and the effective date. For compliance questions, ask for the state(s) of operation, fiscal year, gross assets and issued shares (Delaware franchise tax), and the last 409A date.

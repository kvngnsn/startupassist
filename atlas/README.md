# Atlas workflow adapter

This additive catalog exposes 80 explicit entrypoints while preserving the existing standalone skill and public license. [Browse workflows](CATALOG.md) or inspect [catalog.json](catalog.json).

Existing template/phase wrappers are marked **draft** pending adapter validation; future work is marked **shell**. This does not downgrade or replace the standalone skill. No Atlas production integration is enabled. Tier 1 is a launch candidate, not a guarantee of supported coverage.

Keep all actual company/inventor/matter files outside this public repository. Validate the adapter with `python3 atlas/scripts/validate.py`.
